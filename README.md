## 📖 درباره‌ی متن‌پالا

متن‌پالا یک ابزار هوش مصنوعی ایرانی برای خلاصه‌سازی و پالایش متن‌های بلند فارسی است. 

این پروژه بر پایه‌ی یک مدل آماری مستقل ساخته شده که از صفر روی داده‌های فارسی آموزش دیده. هیچ وابستگی به API خارجی ندارد، تحریم نمی‌شود، و همیشه در دسترس است.

دیتای وزن‌دهی، کد، و مستندات این پروژه به‌صورت اوپن‌سورس منتشر شده‌اند تا جامعه‌ی فارسی‌زبان بتواند از آن استفاده کند و آن را بهبود ببخشد.
